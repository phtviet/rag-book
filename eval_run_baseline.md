**Q:** What is quantization?

**A:** Quantization is a technique that reduces a model's numerical precision, which in turn reduces its memory footprint. For example, reducing a model's precision from 32 bits to 16 bits cuts its memory footprint in half. This technique can be applied at different stages:

**Post-training quantization (PTQ)** is performed after a model has been trained in higher precision. The model is trained using a higher-precision format to maximize performance, and then its precision is reduced for inference. This approach is widely supported by major ML frameworks and works out of the box for many models.

**Quantization-aware training (QAT)** simulates low-precision behavior during training, allowing the model to learn to produce high-quality outputs in reduced precision for inference.

**Direct low-precision training** involves training a model directly in lower precision, which can both reduce training time and costs while also preparing the model for low-precision inference.

Quantization is particularly valuable for inference optimization, as it enables models to run more efficiently on various hardware, including edge devices that may only support quantized inference.

**Q:** What is model distillation?

**A:** Model distillation (also called knowledge distillation) is a method in which a small model (student) is trained to mimic a larger model (teacher). The knowledge of the big model is distilled into the small model, hence the term distillation.

Traditionally, the goal is to produce smaller models for deployment, as deploying a big model can be resource-intensive. Distillation can produce a smaller, faster student model that retains performance comparable to the teacher. For example, DistilBERT reduces the size of a BERT model by 40% while retaining 97% of its language comprehension capabilities and being 60% faster. Similarly, Alpaca, which was created by finetuning Llama-7B on examples generated by a much larger 175-billion-parameter model, behaves similarly to its teacher while being only 4% the size.

The student model can be trained from scratch or finetuned from a pre-trained model. This technique is particularly useful as a use case of data synthesis, where AI-generated data is required rather than just supplementary.

**Q:** What is RAG?

**A:** RAG stands for retrieval-augmented generation. It is a technique that enhances a model's generation by retrieving relevant information from external memory sources, such as internal databases, a user's previous chat sessions, or the internet.

RAG employs a two-step process: it first retrieves relevant information from external memory and then uses this information to generate more accurate responses. This pattern was originally developed to overcome a model's context limitations, as many tasks require extensive background knowledge that often exceeds a model's context window. For example, code copilots might need access to entire codebases, and research assistants may need to analyze multiple books.

RAG enables more efficient use of information, improving response quality while reducing costs. It allows models to circumvent their context limitations and stay more up-to-date. The success of a RAG system depends on the quality of its retriever, which can be either term-based (like Elasticsearch and BM25) or embedding-based, with the latter being more computationally intensive but potentially offering better performance.

**Q:** What are embeddings?

**A:** Embeddings are numerical representations, typically in the form of vectors, that aim to capture the meaning and essence of the original data. They convert complex data into a format that computers can process.

An embedding vector usually contains between 100 and 10,000 elements. For example, a sentence like "the cat sits on a mat" might be represented as a vector such as [0.11, 0.02, 0.54].

A good embedding algorithm produces embeddings where more similar data points have closer embeddings when measured by metrics like cosine similarity. For instance, the embedding of "the cat sits on a mat" should be closer to "the dog plays on the grass" than to "AI research is super fun".

While commonly used for text, embeddings can represent any type of data, including images, products, graphs, queries, and even users. There are also joint embeddings that can map different types of data (such as text, images, and audio) into a unified embedding space.

Embeddings are used in various applications including classification, topic modeling, recommender systems, and retrieval-augmented generation (RAG) systems.

## Q11 [PASS] (factual)

**Q:** What is backward propagation?

**A:** Backward propagation, also known as backpropagation, is the second phase of a training step in neural networks. It is the process of updating the model's weights using the aggregated signals from the forward pass.

The backward pass works through the following steps:

1. **Computing the loss**: The computed output from the forward pass is compared against the expected output (ground truth). The difference between them is called the loss.

2. **Computing gradients**: The process determines how much each trainable parameter contributes to the mistake by calculating gradients. Mathematically, gradients are computed by taking the derivative of the loss with respect to each trainable parameter. If a parameter has a high gradient, it significantly contributes to the loss and should be adjusted more.

3. **Adjusting parameters**: The trainable parameter values are adjusted using their corresponding gradients. The amount of adjustment for each parameter, given its gradient value, is determined by an optimizer (such as SGD or Adam).

This backward pass, combined with the forward pass (which computes the output from the input), forms the complete training mechanism for neural networks.

**Q:** How does entropy and cross-entropy relate?

**A:** Entropy and cross-entropy are closely related concepts that both measure information in bits, but they serve different purposes:

**Entropy** measures how much information, on average, a token carries in a language or dataset. It represents the inherent predictability of the data itself - the lower the entropy, the more predictable the language.

**Cross-entropy** measures how difficult it is for a language model to predict what comes next in a dataset. It depends on two factors:
1. The entropy of the training data itself (H(P))
2. How much the model's learned distribution diverges from the true data distribution, measured by KL divergence (DKL(P||Q))

The mathematical relationship is: **H(P, Q) = H(P) + DKL(P||Q)**

This means cross-entropy equals the data's entropy plus the divergence between the model's distribution and the true distribution. When a language model learns perfectly from its training data, the KL divergence becomes 0, and the model's cross-entropy equals exactly the entropy of the training data. In this sense, a model's cross-entropy serves as its approximation of the training data's entropy.

During training, the goal is to minimize cross-entropy, which effectively means reducing the divergence between what the model learns and the true data distribution.
