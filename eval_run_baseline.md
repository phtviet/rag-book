## Q3 [PASS] (factual)

**Q:** What is model distillation?

**A:** Model distillation (also called knowledge distillation) is a method in which a small model (student) is trained to mimic a larger model (teacher). The knowledge of the big model is distilled into the small model.

The primary goal is to produce smaller models for deployment, as deploying large models can be resource-intensive. Through distillation, a smaller, faster student model can be created that retains performance comparable to the teacher model. For example, DistilBERT reduces the size of a BERT model by 40% while retaining 97% of its language comprehension capabilities and being 60% faster.

The student model can either be trained from scratch or finetuned from a pre-trained model. An example is Alpaca, which was created by finetuning Llama-7B (7 billion parameters) on examples generated by text-davinci-003 (175 billion parameters), resulting in a model that behaves similarly to the teacher while being only 4% of its size.

**Q:** What's the difference between quantization and distillation?

**A:** Based on the provided information, quantization and distillation are two distinct model compression techniques with different approaches:

**Quantization** involves reducing the precision of a model's numerical representations by converting it from a format with more bits to fewer bits. For example, reducing precision from 32 bits to 16 bits cuts the memory footprint in half. This technique directly reduces the model's memory requirements and increases throughput without changing the number of parameters. It's particularly effective and easy to implement, working out of the box for many models.

**Distillation** (or model distillation) involves training a smaller model to mimic the behavior of a larger model. This approach actually creates a new, smaller model with fewer parameters that attempts to replicate the performance of the original larger model. Unlike quantization, which keeps the same model architecture but changes how values are represented, distillation results in an entirely different, smaller model.

In summary, quantization reduces how much space each parameter takes up, while distillation reduces the total number of parameters by creating a smaller model that learns from the larger one.

**Q:** What are embeddings?

**A:** Embeddings are numerical representations in the form of vectors that aim to capture the meaning of original data. Since computers work with numbers, models need to convert their input into these numerical representations that computers can process.

An embedding is a vector - for example, the sentence "the cat sits on a mat" might be represented as [0.11, 0.02, 0.54]. In practice, embedding vectors typically contain between 100 and 10,000 elements, representing complex data in a lower-dimensional space compared to raw data.

Various models are specifically trained to produce embeddings, including open source models like BERT, CLIP (Contrastive Language-Image Pre-training), and Sentence Transformers, as well as proprietary embedding models available through APIs. Different models produce embeddings of varying sizes - for instance, Google's BERT base produces 768-dimensional embeddings, while OpenAI's text-embedding-3-large produces 3072-dimensional embeddings.

Many machine learning models, including GPTs and Llamas, incorporate an embedding generation step as part of their architecture to transform inputs into vector representations before processing.

## Q11 [PASS] (factual)

**Q:** What is backward propagation?

**A:** Backward propagation (or backpropagation) is one of the two phases in training neural networks. It is the process of updating the model's weights using the aggregated signals from the forward pass.

The backward pass works through the following steps:

1. **Computing the loss**: The output from the forward pass is compared against the expected output (ground truth). The difference between them is called the loss.

2. **Computing gradients**: The process calculates how much each trainable parameter contributes to the mistake by taking the derivative of the loss with respect to each trainable parameter. This value is called the gradient - there is one gradient value per trainable parameter. Parameters with high gradients significantly contribute to the loss and should be adjusted more.

3. **Adjusting parameters**: The trainable parameter values are adjusted using their corresponding gradients. The amount of adjustment is determined by an optimizer (such as SGD or Adam, with Adam being the most widely used for transformer-based models).

This backward pass is executed during training (along with the forward pass), but not during inference, which only requires the forward pass.

## Q20 [PASS] (synthesis)

**Q:** How does entropy and cross-entropy relate?

**A:** Entropy and cross-entropy are closely related metrics that measure different aspects of predictability in language models.

**Entropy** measures how much information, on average, a token carries in a language or dataset. It reflects the inherent predictability of the data itself - the lower the entropy, the more predictable the language, and the less information each token carries.

**Cross-entropy** measures how difficult it is for a language model to predict what comes next in a dataset. It depends on two factors:

1. The entropy of the training data (its inherent predictability)
2. How much the distribution learned by the language model diverges from the true distribution of the training data

Mathematically, if P represents the true distribution of the training data and Q represents the distribution learned by the language model, then:
- The training data's entropy is H(P)
- The cross-entropy incorporates both H(P) and the KL divergence DKL(P || Q), which measures how Q diverges from P

In essence, cross-entropy extends the concept of entropy by accounting for both the inherent unpredictability of the data and the model's ability (or inability) to capture that data's true distribution. Both metrics share the same mathematical notation H and are part of a family of closely related metrics used to evaluate language models.
